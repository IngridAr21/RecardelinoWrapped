# Recardelino Wrapped – Juanjo Bona Album Listening Analytics

A personalized **Spotify Wrapped** style project focused on the album *Recardelino* by Juanjo Bona. This project analyzes Spotify Extended Streaming History data to generate insightful listening summaries and key metrics.

---

## Current Status

This project is **under active development**. The backend is implemented using Python and Flask to process and analyze streaming data filtered for Juanjo Bona and the *Recardelino* album. Core analyses include:

- Total listening time (minutes and hours)
- Total streams and play counts per track
- Top listening days and temporal patterns (by year, month, day of week, and hour)
  
The project currently focuses on data processing and generating raw analytics via a Flask API.
